Seluruh folder dan file wajib disusun dengan struktur yang terorganisir, rapi, dan tepat, di mana konten setiap file dibatasi tidak lebih dari beberapa ratus baris untuk menjaga keterbacaan. Penataan ini harus memastikan distribusi file yang seimbang dan tersebar secara logis ke dalam sub-folder yang relevan, sehingga menghindari penumpukan file secara berlebihan dalam satu direktori tunggal.
