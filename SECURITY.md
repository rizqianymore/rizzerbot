# Security Policy

## Supported Versions

Only the latest version of Palantir Bots is supported for security updates. Please upgrade to the latest release before reporting a vulnerability.

| Version | Supported          |
| ------- | ------------------ |
| < 1.0.0 | :x: No             |
| >= 1.0.0| :white_check_mark: Yes |

## Reporting a Vulnerability

If you discover a security vulnerability within this project, please do NOT report it publicly (do not create a GitHub Issue or public Pull Request). Instead, please report it privately through one of the following methods:

- **Email**: Send details of the vulnerability to the owner's contact email.
- **WhatsApp**: Contact the bot owner directly at their configured WhatsApp owner number.

Please provide a clear description of the vulnerability, including steps to reproduce it, proof-of-concept code, or any other relevant information. We will acknowledge your report and work to address the issue as soon as possible.
